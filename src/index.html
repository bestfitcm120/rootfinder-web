Numerical Methods Handbook • Core Formulas

Bisection Method (Interval Halving)

Foundation: Grounded in Bolzano's Intermediate Value Theorem. If a real-valued continuous function satisfies \( f(a) \cdot f(b) < 0 \), there exists at least one root \( r \in [a, b] \).

Midpoint Iteration Formula:
ck = (ak + bk) / 2

Interval Contraction Rule:

  • If \( f(a) \cdot f(c) < 0 \), root lies in lower half: set \( b = c \).
  • Else if \( f(b) \cdot f(c) < 0 \), root lies in upper half: set \( a = c \).
  • If \( f(c) = 0 \), exact root found!
Convergence: Guaranteed global convergence at a linear rate. Each step cuts uncertainty by exactly \( 50\% \) (\( \Delta x_{k+1} = \frac{1}{2}\Delta x_k \)).

Secant Method (Linear Interpolation)

Eliminates the derivative requirement of Newton-Raphson by approximating the tangent with a finite-difference chord between two successive estimates.

Secant Iteration Formula:
xn+1 = xn − f(xn) × [ (xn − xn-1) / (f(xn) − f(xn-1)) ]
Convergence: Superlinear convergence order \( p = \frac{1 + \sqrt{5}}{2} \approx 1.618 \) (the Golden Ratio). Faster than Bisection without needing derivatives.

Newton-Raphson Method (Tangent Line)

Constructs the tangent line at \( (x_n, f(x_n)) \) and follows it down to its x-axis intercept to produce the next approximation.

Newton-Raphson Iteration Formula:
xn+1 = xn − [ f(xn) / f'(xn) ]

In this application, the first derivative \( f'(x) \) is computed using central differences with high precision:

f'(x) ≈ [ f(x + h) − f(x − h) ] / (2h),   h = 10−7
Convergence: Quadratic order \( p = 2 \). The number of correct decimal places doubles every single iteration near simple roots.

The Unified 4-Error Suite

1. Relative Approximate Error (εa)

εa = | (xnew − xold) / xnew | × 100%

Primary Stopping Rule: Iterations terminate as soon as \( \epsilon_a \le \text{tol} \). Scale-independent and realistic in real-world engineering.

2. Absolute Approximate Error (Ea)

Ea = | xnew − xold |

Quantifies the raw displacement between successive steps along the coordinate axis.

3. Absolute Exact Error (Et)

Et = | xtrue − xapprox |

Theoretical benchmark computed when analytical or high-precision true root is provided.

4. Relative Exact Error (εt)

εt = | (xtrue − xapprox) / xtrue | × 100%

True percentage deviation from the ground truth answer.
